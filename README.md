# MarineWatch – Marine Conservation Platform 🌊

## Overview
MarineWatch is a web-based marine conservation dashboard designed to help users record, monitor, and manage marine species observations and environmental conditions.

## Purpose
The project aims to support marine conservation by organising observation records, tracking species, and providing useful reports through a single platform.

## Tools & Technologies
- **HTML** – Structures the web application.
- **CSS** – Provides styling, responsive layouts, and dark/light themes.
- **JavaScript** – Handles form submissions, data filtering, species summaries, navigation, and report generation.

## Implementation
The platform includes five main modules: Dashboard, Observations, Species, Reports, and Settings. Users can add, search, filter, review, and export observation
records. Species summaries and downloadable reports are generated using JavaScript.

## Outcome
MarineWatch provides a simple, interactive interface for managing marine observation data and presenting conservation-related information. It is currently a 
frontend prototype using sample data, with scope for future database integration and real-time monitoring.
